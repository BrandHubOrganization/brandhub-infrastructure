# Terraform Stack `02-frontend` — Route 53, ACM, S3 & CloudFront Edge

- Back to [Terraform Overview](../README.md) · [Production Hub](../../README.md)

Manages BrandHub's public root DNS zone (`brandhub.id.vn`), `us-east-1` TLS certificate, private static asset S3 bucket, CloudFront CDN distribution, and edge viewer-request URL routing for `brandhub-web`.

## 2. CloudFront Viewer-Request Function (`functions/brandhub-public-routes.js`)

Executes at the CloudFront edge prior to cache lookup (`cloudfront-js-2.0`):
1. **Canonical Trailing-Slash Redirect (`301 Moved Permanently`)**: Any non-root URI ending in `/` (e.g., `/pricing/`) is redirected to its clean path (`/pricing`), preserving URL-encoded query parameters.
2. **Pre-Rendered Static Route Rewriting**: Rewrites SEO/legal static directories generated by `brandhub-web` (`/privacy`, `/terms`, `/help/faq`, `/blog`, and extensionless `/blog/<slug>`) to `<uri>/index.html` so S3 serves their pre-rendered HTML directly, while authenticated SPA routes fall through to `/app.html`.

## 3. Input Variables (`variables.tf`) & Outputs (`outputs.tf`)

| Variable | Default | Notes |
| :--- | :--- | :--- |
| `aws_account_id` | *(required 12-digit string)* | Validated via regex (`134875421878` in `terraform.tfvars`) |
| `aws_region` | `"ap-southeast-1"` | S3 origin bucket region |
| `environment` | `"prod"` | Allowed: `dev`, `staging`, `prod` |
| `domain_name` | `"brandhub.id.vn"` | Root public domain |
| `s3_bucket_name` | `"brandhub-web-prd-134875421878"` | Private static frontend S3 bucket |
| `google_site_verification` | `"google-site-verification=..."` | Root TXT verification token |
| `attach_domain_alias` | `false` (`true` once alias released) | Toggles CloudFront `aliases`, SNI ACM cert binding, and Route 53 `A`/`AAAA` alias records |

**Outputs**: `route53_zone_id`, `route53_name_servers`, `s3_bucket_name`, `s3_bucket_arn`, `cloudfront_distribution_id`, `cloudfront_distribution_arn`, `cloudfront_domain_name`, `acm_certificate_arn`.
