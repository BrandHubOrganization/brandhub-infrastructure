Cross-DB Reference Strategy (business-service)
MongoDB
workspaces {
subscriptionId: string // FK to PG
}
Soft reference
No FK constraint
Application-level join
in-memory after 2 queries
PostgreSQL
subscriptions {
id: UUID (PK)
workspaceId: string // from Mongo
}
Rule: business-service queries MongoDB và PostgreSQL riêng biệt, sau đó join trong application memory. Không thực hiện JOIN trực tiếp ở DB engine level. Đây là cách duy nhất cross-DB reference được phép trong hệ thống — ai-service và publisher-service không được biết về cấu trúc này.
business-service
Sole owner của MongoDB, PostgreSQL, Redis. Mọi CRUD đều qua service này. ai-service và publisher-service không được kết nối trực tiếp vào bất kỳ DB nào trong nhóm này.
ai-service
Sole owner của ChromaDB và ghi vào S3. Không bao giờ kết nối MongoDB hoặc PostgreSQL. Lấy business context qua REST API từ business-service khi cần.
publisher-service
Zero DB access. Toàn bộ data (nội dung + token + config) được đóng gói trong RabbitMQ message bởi business-service trước khi enqueue. Sau publish gửi callback HTTP.

PostgreSQL — 4 tables
Table Mô tả
subscription_plans Định nghĩa gói FREE/BASIC/PRO/ENTERPRISE, giới hạn posts · platforms · clients · AI credits, giá
subscriptions Gói đang dùng của từng workspace, trạng thái, ngày bắt đầu/kết thúc, auto-renew
payments Lịch sử thanh toán, transaction ID, invoice number/URL
audit_logs Log mọi hành động user (action, resource, IP, timestamp, JSONB details)
MongoDB — 9 collections
Collection Mô tả
users Tài khoản, role: ADMIN · AGENCY_OWNER · ACCOUNT_MANAGER · CONTENT_CREATOR · BRAND_CLIENT
workspaces Agency workspace, ref → ownerId (user)
clients Brand client thuộc workspace, có accountManagerId
social_accounts OAuth tokens các nền tảng (FB/IG/TikTok…) của client, có tokenExpiresAt
content_requests Yêu cầu tạo nội dung, có assignedTo, status
posts Bài đăng đã tạo, có scheduledAt, status
campaigns Chiến dịch marketing (nhóm posts)
knowledge_documents Tài liệu brand knowledge dùng cho RAG (ai-service đọc qua API)
notifications Thông báo in-app cho user, có isRead
