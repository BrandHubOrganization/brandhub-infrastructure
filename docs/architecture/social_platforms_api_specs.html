Social Platforms API Specifications

Single source of truth for publisher-service integration versions, limits, and schemas

Facebook Graph API

Version Pinned:
v19.0
Authentication:
Page Access Token (Long-lived)
Endpoint:
POST /{page-id}/feed
Rate Limits:
200 calls/hour per user
Gotchas: Page Access Tokens can suddenly expire if the user changes their password or revokes permissions.
Image Payload Example
// POST /v19.0/{page-id}/photos { "message": "Check out this new image! 📸", "url": "https://brandhub.com/media/sample.jpg", "access_token": "{PAGE_ACCESS_TOKEN}" }

TikTok Content API

Version Pinned:
v2
Authentication:
OAuth 2.0 User Access Token
Endpoint:
POST /v2/post/publish/video/init/
Rate Limits:
1000 calls/day per user
Gotchas: Strict video duration limit: 3s min to 600s max. Multi-step pull-from-url approach is required.
Init Video Publish
// Headers: Authorization: Bearer {TOKEN} { "post_info": { "title": "Amazing TikTok Video #viral", "privacy_level": "PUBLIC_TO_EVERYONE" }, "source_info": { "source": "PULL_FROM_URL", "video_url": "https://brandhub.com/video.mp4" } }

Threads API

Version Pinned:
v1.0
Authentication:
OAuth 2.0 User Access Token
Endpoint:
POST /{user-id}/threads
Rate Limits:
250 posts/day
Gotchas: 2-step process (create container, then publish). Max 10 media attachments per post.
Step 1: Create Container (Image)
// POST /v1.0/{user-id}/threads { "media_type": "IMAGE", "text": "Look at this picture!", "image_url": "https://brandhub.com/threads-img.jpg" }

Instagram Graph API

Version Pinned:
v19.0
Authentication:
Page Access Token
Endpoint:
POST /{ig-user-id}/media
Rate Limits:
200 calls/hour
Gotchas: Strict aspect ratios (4:5 to 1.91:1). Requires Professional Account linked to FB Page.
Step 1: Create Container
// POST /v19.0/{ig-user-id}/media { "image_url": "https://brandhub.com/ig-post.jpg", "caption": "Hello Instagram! 📸", "access_token": "{PAGE_ACCESS_TOKEN}" }

YouTube Data API

Version Pinned:
v3
Authentication:
OAuth 2.0 User Access Token
Endpoint:
/upload/youtube/v3/videos
Rate Limits:
10,000 units/day (~6 uploads)
Gotchas: Uploading costs 1,600 quota units! Shorts use the same endpoint (vertical, < 60s).
Init Resumable Upload
// POST .../upload/youtube/v3/videos?uploadType=resumable { "snippet": { "title": "BrandHub Video", "description": "Amazing! #Shorts", "tags": ["brandhub"] }, "status": { "privacyStatus": "public" } }
