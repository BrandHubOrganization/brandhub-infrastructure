# FR 3.10.12 — Import AI Credit Price CSV

## 1. Objective & Business Value

Enable system `Admin` on `/admin/credit-prices` to upload `credit_recommendations.csv` (`<= 64 KiB`, RFC 4180 UTF-8/BOM, `schema_version=1`) generated by the BrandHub GPU benchmark tool, inspect a zero-write diff preview (`POST /api/v1/admin/credit/prices/import/preview`), and atomically apply verified changes (`POST /api/v1/admin/credit/prices/import/apply`) guarded by file `SHA-256` and per-operation `expectedRevisions`.

## 2. User Story

As an authorized `Admin`, I want to execute **Import AI Credit Price CSV** with strong ACID financial/administrative guarantees, deterministic concurrency protection, and complete audit logging so that BrandHub's operations strictly satisfy `BR-30, BR-65` without manual database intervention.

## 3. Acceptance Criteria

1. **Canonical Role & Tenant Security:** Server-side authorization enforces `Admin` on every request (`Admin` verified against live DB `user_system_roles`; `Owner`/`Manager`/`Creator` verified against live `agencies` / `workspace_members`). Unauthorized callers receive `403 FORBIDDEN` (`MSG07`) or scoped `404 NOT_FOUND` on IDOR probes.
2. **Core Domain & Financial Invariants:**
- **1. Strict Benchmark CSV v1 Contract (`credit-price-csv-import`):** Exact ordered header `schema_version,operation,unit_credits,source_report_id,profile_id,width,height,steps,generated_at` (`<= 64 KiB` -> `413 CREDIT_PRICE_CSV_TOO_LARGE` above limit; `1–2` records covering `AMBASSADOR_GENERATE` and/or `COMMERCIAL_IMAGE`, no duplicates; `unit_credits ∈ [0, 9007199254740991]`). `width` and `height` may both be empty (`allDimensions` / `mixedDimensions` feature-level pricing) or valid `256..2752` multiples of `32`; partial dimension pairs are rejected (`400 CREDIT_PRICE_CSV_INVALID`).
- **2. Two-Phase Preview -> Explicit Apply Safety:** `preview` performs zero database writes. `apply` verifies exact `sha256` and `expectedRevisions`, preserves current `enabled` state (new unconfigured operations stay `enabled = false` until explicitly enabled), skips unchanged prices without creating no-op revisions, and rolls back the entire batch on any revision conflict (`409`).
3. **Auditability & Idempotency:** Every mutation records correlation `requestId` and structured audit evidence (`audit_logs` / `billing_audit_events` / `admin_account_operations`), and supports safe retry without duplicate financial side effects.
4. **Internationalization (`vi.json` + `en.json`):** All headings, table columns, status pills, dialogs, validation hints, and error banners use key-parallel translations (`credit.csv.{importButton,previewTitle,applyButton,featurePricing,allDimensions,mixedDimensions,errors.*}` in `src/i18n/locales/{vi,en}/credit.json`) on `brandhub-web` and `tr()` on `brandhub-mobile-app` — zero hardcoded Vietnamese or English text in JSX/TSX.
5. **Light & Dark Mode Compliance:** All components (`pages/credit/prices.tsx`, `pages/credit/components/CreditPriceCsvImport.tsx` (inline review panel, zero extra modal) on Web and `src/screens/admin/AdminCreditPricesScreen.tsx` (displays imported revisions & prices) on Mobile) use semantic CSS variables / Tailwind `dark:` variants and `useAppPreferences().palette` tokens with WCAG AA contrast across Light and Dark modes.

## 4. UI / UX & Screen States

- **Web Surfaces (`brandhub-web`):** `pages/credit/prices.tsx`, `pages/credit/components/CreditPriceCsvImport.tsx` (inline review panel, zero extra modal)
- **Mobile Surfaces (`brandhub-mobile-app`):** `src/screens/admin/AdminCreditPricesScreen.tsx` (displays imported revisions & prices)
- **UI States:**
  - **Loading / Busy:** Skeleton placeholders on initial query; disabled submit button + spinner during in-flight mutation to prevent double-submit races.
  - **Empty:** Contextual localized empty state (e.g. zero invoices/moderation items/users matching filter) with zero fabricated mock data.
  - **Success:** Scoped `TanStack Query` cache invalidation, updated KPI/row state, and localized confirmation toast.
  - **Conflict / Error:** Explicit `409` stale-revision reload prompt or localized validation banner preserving user draft inputs.

## 5. API Contract

| Method & Endpoint | Auth / Guard | Controller & Service Handler |
| :--- | :--- | :--- |
| `POST /api/v1/admin/credit/prices/import/preview` | Bearer (`Admin`), `multipart/form-data` | `CreditPriceImportController.preview()` -> parses CSV via Apache Commons CSV, returns `sha256`, current vs proposed prices, benchmark metadata & row/field issues (0 DB writes) |
| `POST /api/v1/admin/credit/prices/import/apply` | Bearer (`Admin`), `multipart/form-data` (`file` + `request` JSON) | `CreditPriceImportController.apply()` -> re-verifies `sha256` + `expectedRevisions`, locks operations in deterministic order, updates changed prices & audit in one `@Transactional` commit |

## 6. Error Handling & Edge Cases

- `FORBIDDEN` (`403`, `MSG07`): Caller lacks `Admin` permission or attempts cross-Agency/cross-Workspace access.
- `CONFLICT` (`409`, `MSG03`): Stale `expectedRevision` / `rowVersion`, duplicate idempotency key with mutated payload, or prohibited self-sanction/last-Admin demotion.
- `BAD_REQUEST` / `PAYLOAD_TOO_LARGE` (`400` / `413`, `MSG02` / `MSG14`): Invalid date range, negative/unsafe integer amount, malformed CSV, or de-scoped operation (e.g., plan downgrade or non-SePay provider).
