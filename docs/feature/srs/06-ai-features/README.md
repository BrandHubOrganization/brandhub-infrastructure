# 3.7 AI Features (19 FRs)

> **Navigation:** [← Feature Master Index](../../README.md) · [← SRS 141 FRs Index](../README.md) · [BA Domain Spec](../../../ba/06-ai-features.md) · [Extension Modules](../../modules/README.md) · [Workflow Rule](../../../rule/feature-workflow.md)

Canonical business specification, technical implementation plan, sequential task checklist, and unit/integration/UI verification suite for **3.7 AI Features** (`3.7.1 – 3.7.19`, **19 Atomic CRUD Functional Requirements** across `UC-088` to `UC-106`).

## Architectural Overview

- **Services:** `brandhub-business-service` (`AiCaptionController`, `AiGenerationController`, `AiVideoController`, `ProductVideoController`, `AiTrendController`, `WorkspaceTrendController`, `AdminCrawlConfigController`, `AdminTrendGraphController`, `DirectoryPartnerController`, `CollaboratorController`, `ProfileMatchingController`) + `brandhub-ai-service` (FastAPI `/api/v1/ai/*` and `/api/v2/commercial/generate`).
- **Storage & State:** PostgreSQL (`ai_caption_generations`, `ai_video_jobs`, `product_video_productions`, `ai_credit_reservations`, `credit_operations`, `workspace_hashtags`, `third_party_collaborators`, `campaign_collaborators`), ChromaDB (`brand_docs_{workspace_id}`), Neo4j (`Topic`, `Keyword`, `Hashtag`, `Entity` trend graph), Redis (`trends:vn:*` ZSETs), and AWS S3 media buckets.
- **Related Platform Modules:** [`05-ai-rag-and-crawler`](../../modules/05-ai-rag-and-crawler/README.md) · [`06-ai-media-and-video-studio`](../../modules/06-ai-media-and-video-studio/README.md) · [`mobile-ai-features`](../../modules/08-mobile-application/mobile-ai-features/spec.md).
