# Agency Plus renewal

Owner renews Plus via same SePay QR popup; explicit action RENEWAL separate from UPGRADE. Early payment buys one FUTURE period starting current paid period end; expired renewals begin at payment time (clamped to last period end to avoid overlap). At most one future period. Credits granted only when period starts; existing monthly credits expire through append-only ledger. Scheduler activates due periods/expires subscriptions, never changes paid order price/history. API returns paidThrough and renewalScheduled; active/expired Plus can renew, suspended cannot. Each period/key/payment processed once.
