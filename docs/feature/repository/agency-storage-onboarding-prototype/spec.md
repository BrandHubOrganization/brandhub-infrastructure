# Agency storage onboarding prototype
Question: can a non-technical Owner/Manager discover and complete storage setup from the dashboard?
Build three development-only variants on the existing workspace dashboard, gated by storagePreview=1 and variant=A/B/C. A: prominent onboarding card; B: compact notice expanding inline; C: setup checklist next to quick actions. Preserve BrandHub styling and existing data/auth. Simulate not-connected, account choice, connected, Drive full with BrandHub storage, and reconnect states in memory. No OAuth, backend writes, persistence or commits. Label the simulation clearly; do not show S3 jargon or ask users for folder paths. All new copy uses workspace.storagePrototype keys in both vi/en. Verify light/dark, narrow width and keyboard affordances.
