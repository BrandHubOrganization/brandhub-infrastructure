# Task — Content Writing View (FR 3.6.10)

> Status: **Implemented** (V4: canvas + Yjs CRDT real-time sync — see [spec.md](spec.md), [plan.md](plan.md)). Remaining items below are explicitly out of scope for this pass, not blockers.

- [x] **0. Prerequisite**: minimal `Task` entity + basic CRUD — **implemented**, but intentionally not the full FR 3.6.1 Identify Task Detail scope (no assignee, due date, comments). See `Task.java`, `TaskService(Impl).java`, `TaskController.java`.
- [x] **1. Data model**: `TaskContentOperation` (append-only, opaque base64 Yjs update log), `TaskContentSnapshot` (client-reported Yjs state), migrations applied to local DB.
- [x] **2. OT architecture decision**: direction B chosen and implemented — Yjs CRDT, not hand-written OT. See [plan.md §6](plan.md#6-technical-risks-as-realized).
- [x] **3. WebSocket infra (BE)**: `spring-boot-starter-websocket` added, `WebSocketConfig` (STOMP endpoint `/ws/tasks`, broker `/topic`), `WsJwtHandshakeInterceptor` (JWT via query param, reuses `JwtUtil`), `SecurityConfig`/`JwtAuthenticationFilter` updated to permit the WS path at the HTTP layer.
- [x] **4. Canvas rendering engine (FE)** — implemented and browser-verified at `/content-writing`: text layout/measurement, line-breaking, render loop. See `brandhub-web-dashboard/src/pages/content-writing/`.
- [x] **5. Offscreen input capture (FE)** — implemented and browser-verified: hidden off-screen `contenteditable`, Vietnamese IME handling (verified with a synthesized composition sequence), CSS cursor overlay, canvas click-to-position, Backspace/Delete. Text selection (highlighting a range) not implemented. Route gated to CREATOR/MANAGER via `ROUTE_ACCESS["/content-writing"]` (FE) and `@RequireRole` (BE).
- [x] **6. Real-time sync (FE+BE)**: `useTaskContentSync` hook — STOMP client (`@stomp/stompjs`), Yjs `Y.Doc` wired to `CanvasTextEditor`, `TaskContentWebSocketController` persists + broadcasts updates. Browser-verified single-client: type → persisted via WS → reload → content restored correctly from snapshot+operations, in the right order. **Not yet verified with two concurrent browser sessions** (multi-client convergence is implemented per the Yjs/STOMP design but not manually tested end-to-end).
  - **Bug found and fixed during verification**: `appendOperation`'s `count(taskId) + 1` sequence assignment was not atomic — concurrent WS messages for the same Task could compute the same `sequenceNumber`, the loser's INSERT hit the unique constraint and threw, and that update was silently lost (never persisted, never broadcast). A later Yjs struct whose `origin` pointed at the lost one became a permanently unreachable orphan, which looked like "most of what I typed disappeared after reload." Fixed with a per-task `synchronized` lock in `TaskContentServiceImpl.appendOperation`. Also fixed two related client-side bugs found along the way: a stale `caretIndex` closure in `CanvasTextEditor`'s insert/delete handlers (now backed by a ref), and a missing `yDoc.off()` cleanup for the local-update listener in `useTaskContentSync`.
  - Typing fast enough (e.g. scripted `type_text`-style bulk input near-simultaneously) can still drop a keystroke client-side before it reaches the Y.Doc update event — not reproduced with normal human-speed typing in this verification; flagged here rather than silently ignored.
- [ ] **7. Accessibility**: only the pre-existing `aria-live` text mirror exists (from the core-only pass); no shadow-DOM layer beyond that was added. Verified the mirror stays in sync with typed content.
- [ ] **8. Virtualization**: not implemented — content is short-form (social posts), so a single canvas without pagination was judged sufficient for this scope.
- [x] **9. Version History**: REST load/list/restore snapshot implemented (`TaskContentServiceImpl`), `VersionHistorySidebar` UI implemented. Browser-verified: reporting a snapshot via REST makes it appear in the sidebar, and clicking Restore completes without error.
- [ ] **10. Offline queue**: not implemented — `useTaskContentSync` reconnects (`reconnectDelay: 3000`) but has no IndexedDB queue; edits made while fully disconnected aren't persisted if the tab closes first.
- [ ] **11. Font auto-conversion on publish**: not implemented — no publish flow exists yet for Content Writing Tasks to hook into.
