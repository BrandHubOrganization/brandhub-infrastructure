| Version | 2.0 — 2026-09-27 — aligned with PO decisions: direct download vs transcoding export, presigned S3 URL with TTL, workspace tenancy isolation, native formats (PNG/JPG, native MP4) |

## Function Trigger

Begins when a Creator views an AI-generated image (FR 3.7.3, FR 3.7.5) or video (FR 3.7.7), or accesses the Material Asset Library inside a Task (`/workspaces/:workspaceId/tasks/:taskId/materials`), and clicks the "Export" or "Download" action button.

## Function Description

- **Actors / Roles:** CREATOR (Workspace member with access to generated assets).
- **Purpose:** Provide secure, authenticated downloading and format-optimized export of AI-generated assets (images and videos) to local user storage for publishing across social networks, advertising platforms, or client handover.
- **Distinct Execution Modes:**
  1. **Direct Download (Original Native Asset):** Instant access to the raw file generated by FLUX.2 (PNG/JPG) or Google Veo 3.1 (MP4) from private S3 without modification. Returns a short-lived Presigned S3 URL (TTL 15 minutes) with `Content-Disposition: attachment; filename="..."`. Zero GPU compute, zero AI credit cost.
  2. **Transcoding / Processing Export (Format Conversion / Compression / Watermark):** When the Creator explicitly requests format conversion (e.g., PNG to lightweight JPG for web ads), image compression, or Brand Watermark stamping (from FR 3.6.15 Apply Watermark), the system invokes a lightweight backend media processor (Pillow/Sharp for images, lightweight FFmpeg for metadata). Generates a derivative asset in temporary S3 storage and issues a signed download URL.
  - *PO Decision on Video WebM:* Google Veo 3.1 natively outputs `video/mp4`. Because Veo 3.1 does not provide native WebM, and heavy video transcoding is omitted from scope (PO Decision D08), video exports are delivered strictly in native MP4 format.
- **Interface:**
  - Export Modal Dialog: File summary (Asset type, original resolution, file size), Export Mode Selector (`Original File` vs. `Custom Export`), Format dropdown (for images: `PNG`, `JPG`), Quality slider (`100% Original`, `85% Web Optimized`), Watermark toggle ("Apply Brand Logo Watermark", FR 3.6.15), "Download" submit button.
  - Direct 1-Click Download button on video/image cards triggering instant browser file download.
- **Data Processing:**
  - Gateway routes request to Business Service.
  - Business Service validates user workspace membership and confirms that `asset.workspace_id == request.workspace_id`.
  - For Direct Download: Generates an AWS S3 Presigned URL signed via HMAC-SHA256 with a 900-second (15-minute) expiration and attachment content disposition. Returns URL or responds with HTTP 302 Redirect.
  - For Transcoding / Watermark: Resolves source S3 asset, applies transformations in background worker, saves result to `/workspaces/{workspaceId}/exports/{exportId}.{ext}`, and returns signed download link. No AI generation credits are deducted.

## Routes and DTOs

### Public Client Endpoints (API Gateway → Business Service)

- `POST /api/v1/workspaces/{workspaceId}/ai/assets/{assetId}/export`
  - Body: `ExportAssetRequest`
  - Response `200 OK`: `ApiResponse<ExportAssetResponseDto>`
- `GET /api/v1/workspaces/{workspaceId}/ai/assets/{assetId}/download`
  - Query params: `disposition` (default: `attachment`)
  - Response `302 Found`: Redirect to S3 Presigned URL
- `POST /api/v1/workspaces/{workspaceId}/ai/assets/{assetId}/refresh-download-url`
  - Response `200 OK`: `ApiResponse<RefreshUrlResponseDto>`

## Function Details

### Data Specifications

- **Input required:**
  - `workspaceId` (path, UUID): Current workspace context.
  - `assetId` (path, UUID): Target asset ID.
- **Input optional:**
  - `exportMode` (body, enum): `DIRECT` (default) or `TRANSCODE`.
  - `targetFormat` (body, enum): `PNG`, `JPG`, `MP4`.
  - `applyWatermark` (body, boolean): Default `false`.
  - `compressionQuality` (body, enum): `ORIGINAL` or `WEB_OPTIMIZED`.
  - `customFilename` (body, string): Alphanumeric filename sanitization.
- **System data:**
  - PostgreSQL `assets` / `video_jobs` / `image_jobs` tables: Metadata lookup (`s3_key`, `workspace_id`, `mime_type`, `file_size`).
  - S3 bucket objects: Raw generated assets stored in private tenant prefix `/workspaces/{workspaceId}/...`.
  - AWS KMS / S3 Presigner: Generates HMAC-SHA256 authenticated pre-signed URLs with 900s TTL.
- **Output:**
  - `ExportAssetResponseDto` with secure download URL and expiration timestamp.

### Business Rules

- **BR-AI-801 (Strict Workspace Tenancy & Ownership):**
  - Gateway and Business Service MUST verify that the requested `assetId` belongs strictly to the `workspaceId` in the path.
  - If a user authenticated in Workspace A attempts to export an asset belonging to Workspace B, the system MUST return 403 `FORBIDDEN` (or 404 `ASSET_NOT_FOUND` to prevent ID enumeration).
- **BR-AI-802 (Zero Generation Credit Cost):**
  - Exporting an existing asset (both Direct Download and Transcode/Watermark) consumes ZERO AI generation credits.
  - Generation was already settled during the initial creation (FR 3.7.5, FR 3.7.7). Re-exporting an asset must never double-charge.
- **BR-AI-803 (Presigned S3 URL Expiry & Refresh):**
  - Direct download links MUST NOT be public permanent URLs.
  - All URLs are AWS S3 Pre-signed URLs with a maximum TTL of 900 seconds (15 minutes).
  - After 15 minutes, the link expires with an S3 `AccessDenied` error. Clients can refresh the link on demand via `POST .../refresh-download-url` without generating the file again.
- **BR-AI-804 (Format Compatibility Matrix):**
  - Images can be exported as `PNG` (default lossless) or `JPG` (compressed).
  - Videos are strictly exported as `MP4` (Google Veo 3.1 native).
  - Conversion of video to WebM is explicitly omitted (per PO Decision D08). Attempting to request `targetFormat: "WEBM"` results in 400 `UNSUPPORTED_EXPORT_FORMAT`.
  - Mismatched asset conversions (e.g., requesting `targetFormat: "MP4"` on a static PNG image) are strictly blocked.
- **BR-AI-805 (Watermark Stamping Isolation):**
  - Applying a watermark creates a new derivative temporary file in `/exports/` prefix; it NEVER mutates or overwrites the original generated source file in S3.
- **BR-AI-806 (No Re-generation Guarantee):**
  - Export operations strictly read from existing stored assets. Under no circumstances does the export endpoint invoke FLUX.2 or Veo 3.1 generation models.

### Validation

- User not a member of target workspace → 403 `FORBIDDEN`, Display: MSG-AI-01.
- `assetId` does not exist or has been deleted → 404 `ASSET_NOT_FOUND`, Display: MSG-AI-801 ("The requested media asset was not found or has expired.").
- Requesting `targetFormat: "WEBM"` for video → 400 `UNSUPPORTED_EXPORT_FORMAT`, Display: MSG-AI-802 ("WebM export is not supported for Google Veo 3.1 native MP4 video.").
- Incompatible format (e.g., requesting video format for image asset) → 400 `INVALID_EXPORT_COMBINATION`, Display: MSG-AI-803 ("Cannot export an image asset as video.").
- Download URL accessed after 15-minute expiration → S3 returns 403; UI catches expired link and displays inline prompt to refresh: MSG-AI-804 ("Download link expired. Click to refresh.").

## Functionalities

### Normal Flow — Direct Native Download

1. Creator views generated video in Video Studio (FR 3.7.7) and clicks "Export".
2. Creator chooses "Fast Download (Native Original)" and clicks "Download Now".
3. Client submits `POST /api/v1/workspaces/{workspaceId}/ai/assets/{assetId}/export` with `{ "exportMode": "DIRECT" }`.
4. Business Service validates workspace membership and asset ownership (`asset.workspace_id == workspaceId`).
5. Business Service calls S3 presigner to generate a signed download URL with 15-minute TTL and header `response-content-disposition=attachment; filename="{sanitized_name}.mp4"`.
6. Business Service returns `200 OK` with `ExportAssetResponseDto`.
7. Client triggers native browser download via invisible `<a>` element; the browser saves the MP4 file to the user's computer.

### Normal Flow — Transcoding & Watermark Export

1. Creator clicks "Export" on an AI-generated product image.
2. Creator selects "Optimized Export", sets format to `JPG`, checks `[x] Apply Brand Logo Watermark`, and sets position to `Bottom-Right`.
3. Client submits `POST .../export` with `{ "exportMode": "TRANSCODE", "targetFormat": "JPG", "applyWatermark": true, ... }`.
4. Business Service routes job to media processing worker.
5. Worker downloads source PNG from S3, overlays workspace Brand Logo at bottom-right with 15% padding, converts color space to RGB, and encodes as JPG (quality 85).
6. Worker saves derivative asset to `/workspaces/{workspaceId}/exports/{exportId}.jpg` in S3.
7. Worker generates 15-minute Presigned URL for derivative file and returns `200 OK`.
8. Client initiates local file download.

### Abnormal Cases

- 4.a1: `assetId` does not exist in database → 404 `ASSET_NOT_FOUND`, toast MSG-AI-801.
- 4.b1: `asset.workspace_id` belongs to another workspace (cross-tenant attack) → 403 `FORBIDDEN`, audit log entry written, toast MSG-AI-01.
- 5.a1: Underlying S3 object has been purged or deleted by retention policy → 410 `ASSET_STORAGE_GONE`, toast MSG-AI-805 ("Source file is no longer available in storage.").
- 7.a1: Download URL accessed after 15 minutes → Browser shows expired link error. Creator clicks "Refresh Download Link" in UI; client calls `POST .../refresh-download-url` and immediately obtains a new signed URL without reprocessing.

## Post-Conditions

- For Direct Download: No persistent DB records or S3 files created; temporary audit log entry recorded (`action = ASSET_EXPORT_DIRECT`).
- For Transcode/Watermark: Derivative file saved in temporary S3 prefix `/exports/` with 24-hour lifecycle auto-delete rule.
- Original generated asset remains completely untouched in storage. Zero credit deduction recorded on ledger.

## Out of Scope

- Video format transcoding to WebM or animated GIF.
- Cloud-based video rendering with sound effects or audio track multiplexing.
- Direct publishing to social media (handled separately by Publishing module FR 3.8).
