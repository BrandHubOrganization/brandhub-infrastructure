# Contextual hashtag suggestions
Creator explicitly requests suggestions using current caption and selected platform. Gemini uses server-side GEMINI_API_KEY and existing GEMINI_MODEL to interpret intent, audience, topic and tone, then returns at most requested count in descending relevance. Optional Redis trend evidence is context only; never fill with unrelated trends or claim generated hashtags are trending. Suggestions may be generated, not restricted to workspace collection. User selects each tag; no automatic post mutation or collection save. Preserve credit gateway and trusted internal authentication. Provider/config/invalid-output failures are explicit, with no unrelated fallback and no sensitive logs.
UI: numbered vertical list highest relevance first, existing keyboard buttons and semantic theme classes. Parallel vi/en editor.hashtagInput aiGenerate/aiLoading/aiResults/aiRankHint/aiEmpty text. Caption is untrusted data, not instructions. Validate bounded caption/output, deduplicate Unicode case-insensitively, preserve ranking and underscore. Empty valid list is allowed.

Failure diagnosis extension: emit INFO lifecycle logs visible under Uvicorn with generated trace ID, platform, caption length, cache count, provider stage, duration, error category/status and result count. Never log caption/prompt/key/provider body. A definitive hashtag failure response contains a stable trusted failure code; Business may finalize zero successful units only for that explicit code on HASHTAG_GENERATE. Transport/timeouts/malformed upstream remain UNKNOWN and retain reservation.
