## Google Cloud setup (local development)
1. Open https://console.cloud.google.com/ and choose/create the BrandHub project.
2. APIs & Services > Library > Google Drive API > Enable.
3. Google Auth platform > Branding: app name BrandHub, support/contact email. Audience: External for accounts outside a Workspace organization; keep Testing during local validation and add each connecting Google account under Test users.
4. Data Access > Add or remove scopes: https://www.googleapis.com/auth/drive.file. This app creates its own agency/workspace folders; full-Drive access is not required.
5. Clients > Create client > Web application, name BrandHub Drive Local. Authorized JavaScript origin: http://localhost:3000. Authorized redirect URI exactly http://localhost:3000/storage/drive/callback (no trailing slash).
