# Chat attachments and repository references
Web chat supports uploads and repository media in DIRECT/PUBLIC/PRIVATE channels, roots, threads and scheduled messages. Uploads: JPEG/PNG/WebP/PDF, 10 MiB/file, at most five attachments/message; no Agency quota debit and no automatic repository insertion. File-only messages are allowed. Repository selection uses the sender's existing workspace/vault access. Sending never grants rights and never requires every recipient to have repository access. Metadata/preview/download checks the current channel and repository audience of the requesting viewer; deny without leaking name, thumbnail, storage key or signed URL. Capture the selected version and pin its original binary: subsequent overwrites do not alter chat history. Preserve group mentions and the DM mention restriction. Use existing encrypted storage/private read path; no public URL storage or plaintext fallback. Only run migrations on explicit authorization; update fresh init and insert-only sample seeder. No shared DB writes in verification.

Repository picker must stay inside the viewport in narrow or short panels; reuse the shared Popover for collision handling and internal scrolling. Transition focus only after the add menu closes.
