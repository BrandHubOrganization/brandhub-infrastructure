# Backend automatic video editing — 2026-11-10

Implemented locally in Business, AI worker and Video Space. No commit/push or VM deployment performed.

## Try it

Open http://localhost:3000, enter Video Space, select a project and open the AI assistant. Add source images/videos and, optionally, supplied narration. Enter the editing instruction and choose **Dựng video tự động**. The action saves the canonical project, submits a durable job and shows stage/progress. A completed job offers a private MP4 download. Reopening the project resumes the saved job; the original editable timeline is preserved.

The existing manual editor and eight-action AI assistant remain available. This action edits supplied/generated media; it does not generate new Veo footage.

## Scope and operating limits

Supported tools include trims, retiming, freeze frames, supported transitions, titles/captions/callouts, supplied alpha portrait glow, music/SFX and supplied narration mixing. Packaged editorial guides and licensed resources support structured planning. Automatic subject tracking/background removal and arbitrary HyperFrames/Manim execution are not implemented. This is not a claim of full DemoVideo/Nyambe parity.

Local media encryption key lives only in ignored Business `.env`; worker has no AWS/AES keys. Sources are fetched through fixed, authenticated Business routes. VM setup, model volume, limits and operator recovery are documented in `DEPLOYMENT.md`. Ambiguous provider outcomes require reconciliation instead of automatically spending again.

## Review decisions

- Preserve saved source revision and render into a separate immutable output branch; never replace the manual timeline.
- Use durable provider-start fencing and stable job identities to avoid duplicate paid planning after lost acknowledgements.
- Use existing private upload/quota/confirmation flow; no new database migration or pricing catalogue entries required for this feature.
- Close the legacy encrypted-upload MIME mismatch for allowed narration formats while retaining signed grants and exact MIME checks.
- Remove the planner sampling parameter rejected by the actual Claude endpoint.
- Final independent review found recoverable publication expiry treated as terminal. Publication now reacquires the owned session, accepts already-READY receipts and retries only recognized transient/expiry states with the same verified artifact. A scoped reviewer identified expiry-after-PUT as a residual case; the controller added that exact code and proved RED→GREEN in the final 20-test run. There was no further independent review after that last narrow correction.
