## Architecture contract
Business owns auth/owner/workspace, canonical private asset descriptors, idempotency and current credit policy. AI/worker owns typed editorial plan, analysis/render/QC. Reuse existing internal key and storage credentials; no keys in frame/browser. Dedicated worker API can run locally or on Linux VM without importing crawl/NLP app startup. Existing API proxies internal planning to worker, allowing current credit generation service to account for the Claude planning call. Rendering reuses paid planning receipt, does not invent a new free credit operation or auto-pay for new footage.

Public endpoints under `/api/v1/workspaces/{ws}/video-projects/{project}`:
- `POST /auto-edits` with mandatory Idempotency-Key, body `{expected_revision,instruction}` (revision>=1, instruction1..4000). Canonical owner snapshot/assets only. Response202 `ApiResponse<{id,status,stage,base_revision,...}>`.
- `GET /auto-edits/{job}`: owner-scoped progress and output metadata, no storage keys/signed URLs.
- `GET /auto-edits/{job}/content`: authorized private MP4 streaming after COMPLETED, no regeneration/provider refresh. Error leaves originals intact.

Internal worker API base `/api/v1/ai/video-edit` protected X-Internal-Key:
- POST `/plan` accepts source envelope below; returns202 `{job_id,status,stage}` immediately, before probe/ASR/Claude. Cached by stable job ID+fingerprint. GET `/plans/{job_id}` returns stage and completed `{job_id,summary,plan}` or explicit FAILED/RECONCILIATION_REQUIRED. Persist provider_started before Claude; a crashed/unknown provider call must not automatically invoke Claude again. Worker startup resumes deterministic pre-provider work; ambiguous paid provider outcome requires reconciliation.
- POST `/jobs` accepts same source envelope plus approved `plan`; returns202 `{job_id,status,stage}`. Same job+same payload replays; changed input409.
- GET `/jobs/{job_id}` returns status/stage/progress/error and completed output receipt `{output_asset_id,sha256,size_bytes,mime_type,qc}` internally only.
- GET `/capabilities` reports missing tool/model/provider readiness without spending API credit.

Source envelope (snake_case): `{job_id,workspace_id,owner_id,project_id,base_revision,instruction,snapshot,sources:[{asset_id,kind,sha256,size_bytes,mime_type,metadata}]}`. IDs UUID. `kind` video/image/audio. Sources come only from private READY immutable project assets; max20 assets,128MiB each/512MiB total. Worker has configured Business API base only, no caller URL/path/object_key inputs. Download fixed internal `/api/v1/internal/video-edits/{job_id}/sources/{asset_id}` with internal auth; Business checks private job source allowlist and streams verified/decrypted source. Download verifies size+SHA before decoder/model. Source bytes/keys/credentials never enter the LLM prompt; bounded sampled frames and transcript plus selected metadata may.

Output transport: worker POST fixed internal `/api/v1/internal/video-edits/{job_id}/output-session` with `{fileName,contentType,sizeBytes,sha256,metadata}`; Business allocates deterministic output asset ID and existing private media quota/session/capability. Output is limited to128MiB. Worker PUTs the server-issued upload link (only configured Business origin or explicitly configured gateway origin, or HTTPS storage host), then POSTs `/output-complete` with `{sessionId}`; `/output-abort` on known pre-copy failures. Complete returns `{output_asset_id,sha256,size_bytes,mime_type}`. Business output stays a separate READY private asset, does not overwrite snapshot or originals. All internal routes require existing internal key using constant-time comparison and job ownership-derived scope, no actor chosen by caller. Worker never needs storage/AES secrets. Pending output publication is idempotent, including lost session-creation acknowledgments; reuse verified render artifact/hash across recovery.

Revision rule: validate the expected revision on first admission, then persist the canonical immutable snapshot/source allowlist. A later manual revision does not cancel or overwrite this separate output branch. Same-key retries return the original job before checking the latest revision; a changed request with that key conflicts.

Worker plan model is shared Python schema with strict bounded types, finite frame/timing/geometry and known asset IDs. Scope is the active scene; native time is120000ticks/second, distinguish source span from retimed timeline duration. Explicitly reject unsupported active-scene elements/effects rather than silently dropping manual edits. Exact plan is persisted and rendered; LLM-generated commands/filters/code are never executed. Initial output max120s,24/30fps,<=1080x1920 or1920x1080. Render deadline600s, one running renderer per worker by default, bounded queue, durable Mongo job receipts/leases. Worker restart resumes safe unfinished jobs without another Claude/payment call. Output media namespace/quota are server-derived through Business. Failed partial uploads do not become completed receipts. QC: exact integer frame count, duration tolerance<=1frame, dimensions/fps match plan, full decode succeeds, audio peak<=0dBFS, integrated loudness measured/reported (voice master target-16±2LUFS when non-silent); no unmeasured quality-success claim.
